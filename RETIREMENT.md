# Studio and 3D retirement

Effective 22 September 2026, Pixel Fix Studio (the launcher/suite) and Pixel Fix 3D are discontinued. This repository is retained as a read-only historical archive, including its existing releases and source history.

Pixel Fix 2D continues independently as [Pixel Fix](https://github.com/craigsimm/pixel-fix). Download [Pixel Fix v0.2.0](https://github.com/craigsimm/pixel-fix/releases/tag/v0.2.0) and read the [migration guide](https://github.com/craigsimm/pixel-fix/blob/main/docs/migration.md).

The standalone application opens existing `.pfx2d` projects and uses the existing Pixel Fix settings directory. It includes independent project tabs and only OpenAI Sunburst/Flare image generation. Studio is no longer required. Pixel Fix 3D projects are not supported by the standalone 2D editor; keep the historical 3D release if you need to access them.

Future bug reports and development belong in the standalone repository. The successor was extracted from the committed 2D source at `e994bd1a2fb3b90402da8a00a383abcaba512ab8`, preserving filtered history. Local uncommitted experimental work was not included.
